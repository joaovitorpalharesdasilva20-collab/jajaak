Site Pronto para Deploy via FTP

A estrutura de automação com o servidor FTP já foi criada e conectada ao GitHub.

Próximos passos para ativar o envio automático:

  1. Acesse o repositório no GitHub.
  2. Vá em Settings > Secrets and variables > Actions.
  3. Adicione os secrets FTP_SERVER, FTP_USERNAME e FTP_PASSWORD.
  4. Cada nova alteração será enviada automaticamente para seu servidor FTP!
